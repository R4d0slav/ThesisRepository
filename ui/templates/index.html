About This Pipeline

Background, methods, and usage guide for the PSS kinetic modelling workflow.

🌱 What is PSS?

The Plant Stress Signalling (PSS) knowledge network is a manually curated model of Arabidopsis thaliana stress response pathways. It encodes molecular interactions — phosphorylation, transcription factor binding, metabolite production — as a directed network in SBML format.

This pipeline converts that static network into a dynamic kinetic model by assigning rate laws, decay rates, and initial concentrations to every species, then simulating the ODE system under various stress conditions (drought, heat, JA, KO).

⚗️ Model Format

The pipeline outputs an Antimony model — a human-readable ODE format compatible with Tellurium / libRoadRunner. Antimony can be converted to SBML Level 2/3 for interoperability with other tools.

Each reaction follows a Michaelis-Menten or mass-action rate law. Protein decay follows first-order kinetics using experimentally measured mRNA half-lives from the Ath decay rates dataset.

⚡ Nextflow Integration

The pipeline is implemented in Nextflow DSL2. Stages 1–3 run sequentially; within Stage 2, the four parameter-fitting scripts run in parallel. Stage 4 fans out across all defined simulation conditions simultaneously.

Use the -resume flag to restart from the last successful checkpoint — Nextflow's caching layer avoids re-running completed tasks.
